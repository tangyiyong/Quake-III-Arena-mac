# Apple 平台移植任务

## 目标与技术决策

在 macOS ARM64 上加载原版 baseq3 资源并完成机器人对战，再扩展到
iOS / iPadOS。原始 2005 年源码保留，首阶段使用锁定版本的 ioquake3
作为现代化引擎基线；本仓库维护构建、资源准备、验证和后续 Apple 平台改造。
这不是对原始引擎已完成 ARM64 修复的声明。

运行资源位于同级 `Quake 3 Arena/baseq3`。只准备 pak0.pk3 至 pak8.pk3，
不导入 pak8a、自定义地图和旧配置。原始资源不提交 Git。

和 iOS 应用目标；macOS 使用独立平台目标。Intel Mac 在 ARM64 验证后按需加入。

## 验证纪律

构建成功、专用服务器通过、客户端画面正确、iOS 真机通过分别记录，不能相互替代。
模拟器不能替代真机 GPU、触控、温度或签名验证。未授权前不上传二进制或游戏资源。

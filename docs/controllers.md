# macOS 手柄支持

## 范围

基于锁定版本 SDL2 2.32.8 的 GameController API，默认开启。目标设备包括
系统和 SDL 能识别的 Xbox One/Series 与 Nintendo Switch Pro 手柄。
USB/蓝牙的实际可用性取决于设备型号、固件、系统与连接方式；未做实体手柄验收。
Joy-Con 单只/配对、第三方兼容手柄、震动、Steam Input 全局重映射不在本次实现范围。
构建 4 加入 SDL 传感器检测和陀螺仪瞄准；标准 Xbox 手柄没有陀螺仪，不能通过软件补足。

## 默认布局

按物理位置统一 Xbox 与 Nintendo 布局，避免 AB/XY 标注相反造成混乱。

| 操作 | Xbox | Switch Pro |
| --- | --- | --- |
| 移动 / 视角 | 左 / 右摇杆 | 左 / 右摇杆 |
| 射击 / 缩放 | RT / LT | ZR / ZL |
| 跳跃（下方键） | A | B |
| 蹲下（右方键） | B | A |
| 使用道具（左方键） | X | Y |
| 下一武器（上方键） | Y | X |
| 上一 / 下一武器 | LB / RB | L / R |
| 行走 / 蹲下 | 左 / 右摇杆按下 | 左 / 右摇杆按下 |
| 计分板 | View / Back | Minus |
| 暂停菜单 / 返回 | Menu / Start | Plus |
| 菜单导航 | 左摇杆或十字键 | 左摇杆或十字键 |
| 菜单确认 / 返回 | A / B | B / A |

游戏中十字键上/右/下/左选择武器槽 2/3/5/7。
默认死区 18%；右摇杆水平最大约 197 度/秒、垂直约 147 度/秒。
菜单摇杆阈值 50%，支持按住重复导航。

## 设置窗口（构建 4 起）

- macOS 顶部应用菜单 →「手柄与显示设置…」。
- 快捷键 Command+, 或 F10；部分 Mac 键盘需 Fn+F10。
- 可用的 Guide 键也可打开；系统或其他软件可能截获该键。

页面可调整手柄开关、摇杆死区、水平/垂直视角速度、反转、陀螺仪、校准及全屏。
采用可滚动内容和固定底部应用按钮，适应较小的可用桌面。打开设置期间暂停游戏输入，
关闭后恢复；游戏网络循环继续运行。只在首次配置时默认窗口化，后续保留全屏选择。

## 陀螺仪瞄准

默认关闭。连接带传感器的设备后，在设置窗口中启用；默认按住左扳机时瞄准，
也可选择在游戏中始终开启。菜单、失焦和设置窗口期间不转动游戏视角。

只有 SDL 实际检测到陀螺仪时才启用设置控件。Switch Pro 的可用性取决于连接方式
和驱动提供的数据，实体 USB/蓝牙仍需验收；不宣称所有 Switch 兼容设备都可用。

校准时把手柄保持静止约 1 秒；移动过大、样本不足或不稳定会提示重试。
偏置仅针对当前连接保存在内存中，重新连接后需重新校准。
灵敏度以 1:1 为基准、范围 0.1–4 倍，支持垂直反转。

## 控制台设置

首次启用本移植版手柄配置时应用默认绑定，以后保留用户修改。
不会修改键盘和鼠标绑定。可在 Quake 控制台中调整：

```text
joy_threshold 0.18
j_yaw -0.006
j_pitch 0.0045
bind PAD0_A +moveup
bind PAD0_RIGHTTRIGGER +attack
```

恢复默认：`arena_gamepadReset`。如手动禁用过手柄，恢复后执行 `in_restart`。
禁用：`in_joystick 0`，再执行 `in_restart`。
选择不同设备：`in_joystickNo N`，再执行 `in_restart`。

设备热插拔/重映射时重建 SDL 连接，优先识别有标准映射的手柄；重建连接、
切换到后台时释放手柄按键和模拟轴。按键在菜单切换后仍释放最初产生的键，
避免跳跃/射击粘住。菜单接管后清零游戏模拟轴。

## 验证

`python3 tools/apple-port/test_gamepad.py` 使用真实 SDL 虚拟设备 API 和引擎事件
队列替身，分别以 Xbox / Switch Pro 的厂商产品标识创建虚拟手柄，验证：

- 游戏到菜单切换后的按键释放保持一致；
- 菜单确认键、摇杆方向、按住重复及退出菜单后的方向释放；
- 断开/失焦清理路径释放按钮、扳机和全部游戏模拟轴。

新增数学回归覆盖可用窗口约束、陀螺仪弧度转角度、60/125 Hz 一致性、
偏置/死区、反转、无效读数以及长帧保护。
虚拟设备和数学验证不覆盖实体 HID 协议、陀螺仪采样、蓝牙配对、无线延迟或固件。
发布前应分别连接真实 Xbox 和 Switch Pro，验收冷启动、热插拔、双摇杆、
扳机、菜单、失焦恢复以及同时按住键鼠和手柄的行为。

SDL 按物理位置映射依据：
https://wiki.libsdl.org/SDL2/SDL_HINT_GAMECONTROLLER_USE_BUTTON_LABELS

传感器单位与轴定义：https://wiki.libsdl.org/SDL2/SDL_SensorType
